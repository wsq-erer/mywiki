### 了解hping3
`hping3`

运行的命令工具。

`-c 10000`

设定发送 10000 个数据包（由于 `--flood`

 的存在，此限制通常被忽略）。

`-d 120`

设定每个数据包包含 120 字节的数据负载。

`-UDP/icmp  -S -A`

强制使用 UDP/icmp/ 协议进行测试。 TCP SYN /ACK 洪泛测试  

`-w 64`

设置 TCP 窗口大小为 64（对当前 UDP 模式无效）。

`-p 80`

指定目标机器的接收端口为 80。

`--flood  ` 

洪水模式，以最高速度发送数据包，不等待且不显示回应。

`--rand-source`

随机生成虚假的源 IP 地址，用于隐藏真实发送者。

`192.168.203.185`

接收测试或攻击的目标 IP 地址。

| `AP_MAC_ADDRESS` |  AP 的 MAC 地址 (BSSID) | `a2:0a:c3:bf:7f:ca` |

| `AP_CHANNEL` |  AP 当前使用的无线信道 | `12` |
| `AP_MAC_DIFFERENT_FREQUENCY` |  AP 在其他频段（如 5GHz）下的 MAC 地址 | `9c:9d:7e:92:32:60` |
| `CHANNEL_DIFFERENT_FREQUENCY` |  AP 在其他频段下的无线信道 | `36` |
